# Ultima V Native v0.5.0 RC2 candidate

Unpublished candidate for final Windows and T-Deck acceptance; hardware validation is pending.

- DOS Save Transfer consistently names original DOS save import/export. Conversion, file formats and paths are unchanged.
- Historical title choices and all shortcuts remain. Native utilities have a little more separation; Settings values align and categories identify related options.
- Windows Settings advertise **F10: System Menu**. Alt+M remains available, Ctrl+M retains music mute, and F1 remains unmapped. T-Deck displays its existing **Alt+M** reminder.
- The original automatic View and the input-driven Summoning remain accessible. The View caption now reads **Original Introduction**, without an internal asset filename.
- Windows Original retains DOS gameplay presentation and restrictions; Enhanced retains its menus and conveniences; T-Deck retains its hardware controls and layout.

Ultima IV character transfer remains unavailable. Final evidence, exact source/artifact identities, static firmware measurements and manual acceptance requirements are in [the UI polish record](docs/V050_FINAL_UI_POLISH.md) and its linked external manifest.
