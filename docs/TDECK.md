# LilyGO T-Deck Plus installation — v0.5.0

Supported hardware: **LilyGO T-Deck Plus, ESP32-S3, 16 MiB flash and 8 MiB octal PSRAM**, with its keyboard, trackball, 320×240 display and microSD card. Other T-Deck variants have not been qualified by this release.

Use the existing bmorcelli T-Deck Launcher SD installer. No specific minimum Launcher version was established; the documented installer rounds app allocations to 64 KiB. Keep a working Launcher and your previous firmware available. [Launcher engineering details](../native/targets/tdeck/LAUNCHER.md).

1. Back up your complete SD card, especially `/ultima5/saves`, settings, import and export files. Use a FAT-formatted microSD card.
2. On a Windows computer, download and extract the [Windows ZIP](https://github.com/thekojac304/ultima-v-native/releases/download/v0.5.0/UltimaV-Native-v0.5.0-Windows-x64.zip). Follow [data preparation](WINDOWS.md) with Node.js and your legally obtained DOS installation. You may use the preparation script without playing the Windows game. From source, the equivalent is `npm install`, then `node --import tsx native/tools/asset-prep/prepare.ts --game "<DOS folder>" --out "<SD drive>/ultima5"` from the repository root.
3. Copy the generated packs into `/ultima5/` at the card root. Preserve existing saves/settings rather than replacing the whole folder. Older packs may need regeneration with the v0.5.0 tooling if validation reports a mismatch.

```text
/ultima5/
  openu5-assets.bin
  openu5-alpha1-resources.bin
  openu5-audio.bin           optional music capability/song pack
  saves/
  settings.json
  import/SAVED.GAM          optional DOS import pair
  import/SAVED.OOL
  export/slotN/             generated by export
```

4. Download [UltimaV-Native-v0.5.0-TDeck-Launcher.bin](https://github.com/thekojac304/ultima-v-native/releases/download/v0.5.0/UltimaV-Native-v0.5.0-TDeck-Launcher.bin). Verify [SHA256SUMS.txt](https://github.com/thekojac304/ultima-v-native/releases/download/v0.5.0/SHA256SUMS.txt) on your computer if desired.
5. Copy the BIN onto the SD card in a location visible to your Launcher's SD browser. Safely eject the card, insert it and start the Launcher. Use its SD installer to select/install this BIN, then launch the installed application. Exact installer labels depend on your Launcher version.
6. On first boot, allow the game to validate its packs. Use Settings to choose interface, text size, audio, brightness/backlight and trackball preferences. Create a character or continue a compatible saved journey.

**This BIN is a bare Launcher application image, not a merged full-flash image.** It does not include a Launcher, bootloader or partition table. Do not flash it as a complete device image or use a standalone esptool flash procedure for this installation. The file is 1,075,504 bytes; Launcher allocation is 1,114,112 bytes (38,608 free), and the build's 1,310,720-byte app partition has 235,216 bytes free.

## Playing, saves and sound

Use the keyboard for commands/text and the trackball for direction/menu navigation. Trackball click toggles WASD movement mode; speed has ten levels. Enter accepts and Esc backs out where the current prompt supports it. **Alt+M — System Menu** (the Mic shortcut is also supported). Save Game/Load Game manages three slots with previous-generation backups; Journey Onward uses the last saved slot. Back up saves before upgrades. [Controls](NATIVE_CONTROLS.md).

Title → DOS Save Transfer imports the pair under `/ultima5/import` and exports to `/ultima5/export/slotN`. Leave dungeons before transfer. [Compatibility and limits](SAVE_COMPATIBILITY.md).

Sound effects do not require music. Stock DOS Ultima V has no music. To enable optional music, prepare the audio pack from compatible Exodus Ultima V Upgrade assets and include `openu5-audio.bin`; songs and game data are not distributed. Settings explains unavailable music capability.

## Troubleshooting and rollback

If packs are missing/invalid, check card mounting, FAT formatting, the exact `/ultima5/` root folder and filenames, then regenerate packs using this release's tooling. Do not place them in a second nested `ultima5` folder. If settings do not persist, check card writability and save a backup before repairs. If Launcher refuses installation, check available app space and that the BIN completed downloading; do not substitute a complete-flash image.

To roll back, return to your Launcher and reinstall your retained older app image through its SD installer. The [v0.4.0 release](https://github.com/thekojac304/ultima-v-native/releases/tag/v0.4.0) remains available. Restore the corresponding backed-up saves/settings if needed; do not assume every older build can read all newer states.
