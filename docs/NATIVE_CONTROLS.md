# Native controls

Windows: **F10 — System Menu**, also Alt+M. T-Deck: **Alt+M — System Menu**, also the Mic shortcut. The menu provides resume, saves, load, settings and return to title.

Original command letters are shared: A Attack, B Board, C Cast, E Enter, F Fire, G Get, H Hole up, I Ignite, J Jimmy, K Klimb, L Look, M Mix, N New order, O Open, P Push, R Ready, S Search, T Talk, U Use, V View, X X-it, Y Yell, Z Z-stats. Space passes. Windows Original Q asks Y/N to save.

Windows uses arrows for direction; T-Deck uses its trackball and keyboard. Enter accepts menu choices. Original preserves contextual DOS input: Yes/No prompts take Y/N; typed text uses Enter to answer and Esc to erase; direction prompts accept a direction or Space. Enhanced adds selection panels and broader cancellation. Interface changes do not rewrite a journey's difficulty/cheats.

Windows system keys: Alt+Enter/F11 fullscreen, Ctrl+= / Ctrl+- size, F12 screenshot, Ctrl+O data folder, F7/Ctrl+M music, F8/Ctrl+S sound. Enhanced only: F5 quick save, F9 quick load, F2 WASD movement, Alt+D Developer menu. T-Deck trackball click toggles WASD movement; speed/backlight are configurable.
