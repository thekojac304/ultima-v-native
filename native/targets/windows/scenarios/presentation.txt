# Classic Framed and the window, checked on the presented frame itself: every
# window_layout reads the window back from the renderer and compares it with
# the layout colour for colour (picture at a whole-number scale, centred, the
# ring's rule and band, black elsewhere). SDL's offscreen driver has one
# 1024x768 display and no window frame, so Window 3x framed (1008x768) is the
# largest window and fullscreen is 1024x768. The expected values are worked
# out by hand from the rules in src/app/presentation_layout.h.
frames 5
expect scaling Framed
expect fullscreen 0
# First run: no saved scale, display scale 1.0 -> Window 3x, framed.
expect window_scale 3
expect window_layout 1008x768 full 960x720@24,24
expect picture_sampling nearest
window_screenshot window-framed-3x.bmp
screenshot panel.bmp
