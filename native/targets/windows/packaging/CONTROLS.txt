ULTIMA V NATIVE for Windows -- KEYBOARD
=======================================

The game uses the original 1988 keyboard. Desktop keys that the original did
not have (function keys, Ctrl and Alt chords) never replace an original
command letter.

COMMANDS (both modes, as in the 1988 game)
  A  Attack            K  Klimb             T  Talk
  B  Board             L  Look              U  Use an item
  C  Cast a spell      M  Mix reagents      V  View (needs a gem)
  E  Enter             N  New order         X  X-it (leave a vehicle)
  F  Fire              O  Open              Y  Yell
  G  Get               P  Push              Z  Z-stats
  H  Hole up & camp    Q  Quit & save (Original mode; see below)
  I  Ignite a torch    R  Ready             Space  Pass a turn
  J  Jimmy a lock      S  Search            1-6 / 0  set / clear the active player
Commands that need a direction ask for it ("Look-"): answer with an arrow.
In Original mode Space answers "Pass" and Esc does nothing there, as in 1988.

MOVING AND CHOOSING
  Arrow keys           move; choose in menus and lists; aim
  Numpad 8 4 6 2       the same, with Num Lock off
  Enter                accept / confirm
  Esc                  cancel / back (Enhanced; Original: see below)
  Backspace            back; erase while typing
  PgUp / PgDn          scroll the message console (also Shift+Up / Shift+Down)
  1-6 in "Player:"     highlight that party member; Enter or Space chooses
                       (as in 1988)
  Dungeons: Up = forward, Down = back, Left/Right = turn

ORIGINAL MODE: THE 1988 PROMPTS
  "Player:"            the party list itself is the menu: the chosen row is
                       shown in reverse video and the panel says "Select:";
                       arrows move (they stop at the ends), 1-6 move to that
                       member, Enter or Space chooses, Esc answers "None!"
  Typed answers        (Talk, Yell, the shrine, how much, how many hours...)
                       letters appear in capitals; Esc ERASES what you typed
                       and the question stays; only Enter answers. An empty
                       answer in Talk ends the conversation (BYE).
  Yes/No questions     only Y or N answer (Enter and Esc are ignored; leaving
                       a town also takes Esc as No)
  Directions           arrows; Space = Pass; Esc and Enter are ignored
  Enter / Esc          at the command prompt: "What?" (outside an arena they
                       do not pass a turn)
  Shops                questions take Y or N; Esc does not leave a shop
                       menu; the healer and the innkeeper ask "Who...?" on
                       the party list
  In an arena          Esc is Escape (flee); Enter and Backspace say "What?";
                       A then Esc loses the swing ("Nothing!"); a cancelled
                       spell, Ready, Use or Z-stats ends that member's turn
  Ready / Z-stats      always ask "Player:" (0 in Z-stats shows the party's
                       equipment); Esc leaves Ready's list, Space or Esc
                       closes Z-stats ("Done")
  ENHANCED mode keeps the menus and the key bar: Esc cancels, Enter passes a
  turn, lists and panels for choosing a member.

CASTING AND MIXING
  ORIGINAL mode: type the first letter of each syllable, as in 1988, then
  Enter (or Space):   I L = IN LOR    V F = VAS FLAM    A X C = AN XEN CORP
  The order does not matter, and a repeated letter counts once (I I L is
  also IN LOR). Backspace removes the last syllable; Esc cancels ("None!").
  J and O have no rune and are ignored. Mix asks "For what spell?" the same
  way; a name that is no spell still goes on to the reagents, as in 1988.
  ENHANCED mode: choose the spell from a list (arrows, Enter).

SYSTEM
  F10 (or Alt+M)       System Menu: resume, save, load, settings, title
  Q                    Original mode: "Save game?" -- Y saves the journey in
                       its own slot, N does not; only Y or N answer (as in
                       1988, the game continues)
  F7 / Ctrl+M          music off / on for this session
  F8 / Ctrl+S          sound off / on for this session (Ctrl+S as in 1988)
  Alt+Enter or F11     fullscreen / window
  Ctrl+= / Ctrl+-      larger / smaller window (1x up to the largest that
                       fits the screen, as Settings -> Display steps)
  Settings -> Scaling  Framed (the default) / Whole pixels / Fit window
  F12                  screenshot (data folder\screenshots)
  Ctrl+O               open the data folder (the game's files are in its
                       ultima5 folder: saves, PC import/export, logs)
  Alt+F4               close the game (it does NOT save: save first)
  On keyboards with AltGr (German, French, ...), AltGr types its characters;
  use the LEFT Alt key for the Alt chords.

ENHANCED MODE ONLY  (Settings -> Interface: Enhanced)
  F5 (or Alt+S)        quick save in the journey's slot
  F9 (or Alt+L)        quick load the journey's slot
  F2                   WASD movement mode on/off (W A S D move while it is on)
  Alt+D                Developer menu
  System Menu          Difficulty and Cheats

TITLE MENU
  J C T U A R S P      the menu entries' hot keys (Journey onward, Create,
                       Transfer, U5 intro, Acknowledgements, Return to view,
                       Settings, PC save transfer); arrows + Enter also work
