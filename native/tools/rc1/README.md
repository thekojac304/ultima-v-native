# v0.5.0 RC1 evidence tools

These tools operate on the current checkout and its active toolchains. They do not publish, push, merge or flash anything. Keep the ignored evidence/build directories: ignored files can hold the only frozen reference or installable package.

1. Configure/build host with `OPENU5_ENABLE_DEVELOPER_TOOLS=ON`, `OPENU5_BUILD_RC1_DIFFERENTIAL=ON`, `CMAKE_EXPORT_COMPILE_COMMANDS=ON`. Run the complete `ctest --test-dir native/core/build-rc1 -j 1 --output-on-failure` serially, without concurrent compilation.
2. Before optimization, run `rc1_tdeck_reference` on the two private packs with no extra argument and with `--paced`; retain `reference-unpaced.txt`, `reference-paced.txt` plus the original executable. The baseline's source is recorded in `docs/V050_RC1_BASELINE.md`. Do not regenerate these frozen files from the optimized candidate.
3. `python native/tools/rc1/differential_check.py --reference <host-build>/rc1_tdeck_reference.exe --candidate <host-build>/rc1_tdeck_handheld.exe --baseline-dir <frozen-evidence> --output <new-evidence-directory>` checks all 1,065 walks / 8,514 snapshots in both modes, exact bytes and a DOS positive control.
4. Export ESP-IDF 6.1; `idf.py --no-ccache -B build-rc1-optimized reconfigure`, then `ninja -C build-rc1-optimized -j 4`. The normal project warnings-as-errors and post-build budget remain enabled. Run `firmware_report.py <build>` on that active toolchain for ELF, symbol and individual `.su` frame estimates; do not interpret compiler frames as whole-stack bounds or `.ext_ram.dummy` as allocated PSRAM.
5. Configure Windows with `UV_VERSION_SUFFIX=rc1`, `CMAKE_EXPORT_COMPILE_COMMANDS=ON`; build with `native/targets/windows/tools/build-windows.ps1 -Test`. It uses the pinned SDL source release and static MSVC runtime; no VC++ redistributable is required. An offline SDL source override must come from the verified release archive.
6. `verify_capabilities.py <compile_commands.json> --handheld` requires the fixed capability and warning/stack flags on every shared firmware translation unit. Omit `--handheld` for Windows. `mutation_check.py <host-build> --firmware-commands <firmware>/compile_commands.json --windows-commands <windows>/compile_commands.json` kills six capability mutants and two wiring mutants, and restores exact header bytes. Run it with no concurrent builds. Compile failures are errors, never counted as killed mutants.
7. Commit all intended source and documentation before final builds. Configure again so Git identities update. Build Windows with `-Test -Package -PackageName UltimaV-Native-v0.5.0-rc1-Windows-x64`; run the established `native/targets/tdeck/package_launcher.py --build-dir <firmware>` and copy its validated app image to `native/targets/tdeck/dist/UltimaV-Native-v0.5.0-rc1-TDeck-Launcher.bin` without changing bytes. Never reuse an old binary with a new label.
8. `package_smoke.py <ZIP> <fresh-output-directory>` extracts the whitelist package, tests missing assets under SDL offscreen (exit 10), generates all three packs from the user's own game via the bundled script, verifies their hashes, and runs portable boot plus Original/Enhanced Look, Enhanced prices and Original DOS panels. The ZIP remains asset-free. It uses a restricted runtime PATH for the actual executable.
9. `release_manifest.py --windows-zip <ZIP> --windows-build <build> --firmware-bin <BIN> --firmware-build <build> --evidence <evidence> --smoke-summary <smoke>/package-smoke-summary.json --output <dist>/v050-rc1-manifest.json` checks clean source, same embedded commit, PE x64, ZIP whitelist/CRC, firmware header/checksum/SHA, expected RC versions, full-suite totals, final differential/mutation evidence, and smoke identity. Its artifact manifest stays outside tracked source to avoid a self-referential commit/hash.

Exact local build paths, commands, results, limitations and handoff are in `docs/V050_INTEGRATION_RC1.md`. Future public release requires the user's physical acceptance and an explicit publication request.
